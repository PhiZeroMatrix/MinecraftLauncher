CrispyBox Launcher: Technical OverviewCrispyBox is a lightweight, minimalist custom Minecraft launcher built with Python. It features a modern Graphical User Interface (GUI) powered by PySide6 (Qt for Python) and uses the minecraft-launcher-lib library to handle core game installations and execution logic.Architecture and Core ComponentsThe codebase utilizes an asynchronous, multi-threaded design to keep the user interface responsive during heavy network operations.1. Asynchronous Backend (LaunchWorker Class)Inheritance: Inherits from QThread to offload resource-heavy operations from the main UI thread, preventing "Not Responding" freezes.Core Tasks: Fetching game files, downloading required assets/libraries, verifying file integrity, building Java execution arguments, and executing the game binary via subprocess.Communication: Emits custom Qt Signal objects (progress_update, status_update) to pass download milestones and log strings safely to the UI thread.2. User Interface (CrispyBox Class)Layout Design: Utilizes a strict vertical layout (QVBoxLayout) housed inside a fixed dimensions window (500x650 pixels) for a compact desktop widget feel.Dynamic Content Loading: Auto-scans an /asset subdirectory for crispy.png to dynamically apply high-quality, smoothed window icons and logo branding elements.UI Controls:QLineEdit: A sanitized input field for the player's offline nickname.QListWidget: A scrollable list populated dynamically with official Minecraft release versions directly from Mojang API.QProgressBar & QLabel: Dynamic visual indicators that toggle visibility based on current network tasks.QPushButton: Styled with a custom CSS string to display a high-contrast, modern green "PLAY" button.Application WorkflowDirectory Isolation: On launch, the script maps the default system Minecraft directory path and modifies it to point to a custom folder named .crispybox. This keeps your client's data isolated from standard installations.API Handshake: The app requests the official version manifest list. If a connection failure or timeout occurs, it falls back gracefully by populating a default static release option (1.20.1).Download and Launch: When the user triggers the "PLAY" routine, input states are validated. The app downloads missing .jar files or assets, handles callback integers to drive the progress bar, and triggers the local Java client.
